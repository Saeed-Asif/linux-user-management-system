# Linux User Management System (Bash Project)

## 📌 Overview

This project is a simple **Linux User Management Automation System** built using **Bash scripting**.
It helps automate basic user-related tasks and is designed for learning DevOps/Linux fundamentals.

---

## 🚀 Features

* Add new users
* Delete existing users
* Show system messages using functions
* Simple menu-driven structure (can be extended)
* Beginner-friendly Bash scripting practice

---

## 🛠️ Tech Stack

* Bash (Shell Scripting)
* Linux (Ubuntu)
* Git & GitHub

---

```
user-management/

```

---

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone git@github.com:Saeed-Asif/linux-user-management-system.git
```

### 2. Move into directory

```bash
cd linux-user-management-system
```

### 3. Give execute permission

```bash
chmod +x script.sh
```

### 4. Run the script

```bash
./script.sh
```
